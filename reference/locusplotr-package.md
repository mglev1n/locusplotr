# locusplotr: Create Regional Association Plots

Description: This package allows the user to obtain linkage
disequlibrium data for any contiguous region within the genome using the
LocusZoom API <https://portaldev.sph.umich.edu/>. By integrating this LD
information with results from a genome-wide association study (GWAS) the
user can create regional association plots.
